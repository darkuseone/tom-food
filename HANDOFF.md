# Перенос из ТОМ-ТУР → канал про блюда (пакет для нового репозитория)

Этот пакет — стартовый набор для второго канала с тем же ведущим (кот Том), но про **историю блюд**.
В репозиторий `tom-tur` про новый канал ничего не записано (решение владельца 19.10.2026).

## Что лежит в пакете
- `CLAUDE.md` — инструкция для Claude Code в новом репозитории (черновик v0, правится после первых выпусков).
- `docs/channel.md` — концепция канала, чем отличается от ТОМ-ТУР, бренд-приёмы.
- `docs/episode-formula.md` — формула ролика про блюдо + меню вариаций против «конвейера».
- `docs/market.md` — анализ ниши и конкурентов (19.10.2026), риски политики YouTube, перелив трафика.
- `docs/dishes.md` — очередь блюд с черновыми хуками (факты ПРОВЕРИТЬ перед сценарием).
- `docs/lessons.md` — что уже выучено на ТОМ-ТУР (статистика, правки владельца) — переносится как есть.
- `bootstrap.sh` — копирует движок, риг Тома, инструменты, звуки и шрифты из `tom-tur`.

## Как развернуть (в новой сессии Claude Code)
1. В новом репозитории: скопировать содержимое этого пакета в корень.
2. `bash bootstrap.sh /путь/к/клону/tom-tur` — переносит переиспользуемое:
   - `engine/` целиком (canvas-движок, HUD, **риг Тома `tom.js` со всеми костюмами**, page.html, gsap);
   - `tools/` (озвучка, prep_voice, build_data, mix, render, cover, check, shot, dbg, evdump, est, libindex, new_episode, setup) — без `tools/bin` (скачивается `setup.sh`);
   - `assets/tom/` (модельный лист, фото кота), `assets/fonts/`, `assets/sfx/` (+ CATALOG.md), `package.json`;
   - `.claude/skills/episode|fix|stats` — как основа (тексты переписать под блюда, см. ниже);
   - `docs/api.md`, `docs/character.md`, `docs/costumes.md`, `docs/sound.md`, `docs/pipeline.md`, `docs/library.md`, `docs/style.md` — справочники движка.
3. НЕ переносить: `episodes/` (выпуски городов), `docs/cities.md`, `docs/sources/`, `docs/stats.md` (свои цифры — свои), `assets/brand/` (у канала будет свой аватар/баннер).
4. После копирования — правки (сделает Claude в новой сессии):
   - `tools/new_episode.py`: каркас эпизода берёт из прошлого выпуска нового канала; первый выпуск — каркас 004-almaty из tom-tur (лежит в клоне);
   - `engine/core.js` HUD: табличка «год + подпись» → **карточка рецепта** (см. `docs/channel.md`, «Визуальная разница»), плашка `ТОМ-ТУР` → новое имя канала;
   - `.claude/skills/episode/SKILL.md`: «город» → «блюдо», формула — из `docs/episode-formula.md`;
   - `tools/config.json`: голос тот же (Дмитрий, `hU3rD0Yk7DoiYULTX1pD`, eleven_v4), ключ `ELEVENLABS_API_KEY` — в переменные окружения нового environment.
5. Бренд: `tools/brand.cjs` → новый аватар/баннер (Том в фартуке шефа + вилка, тёплая палитра).

- Фраза-бренд вместо «Отматываем время!» (варианты там же).
- Первое блюдо (рекомендация — в `docs/dishes.md`).
