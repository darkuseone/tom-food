## Отброшено
- «Первый яблочный — только 1827 (Анна Дорн)»: министерство пишет, что яблочные начинки есть уже в книгах XVIII в.; у Дорн — «ausgezogener Apfelstrudel». Противоречие → в ролик только «в XVIII веке пришли яблоки».
- Кондитер «Ритца» ездил в Будапешт «в первой половине XIX в.» — парижский Ritz открыт в 1898, анахронизм.
- 1699 «Granat-Apffel»: тесто зовут «испанским» — один источник.
- Бургенланд: штрудель на Новый год «хоть из золы» — один источник.
- Число штруделей в рекорде 2025 (8940 у Гиннесса vs 5874 у euronews) — противоречие, не называем.
- Техас: штрудель — официальная выпечка штата (2003) — один источник.
