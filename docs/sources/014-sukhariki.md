## Отброшено
- «Старейший сухарь — 1852, Кронборг» — опровергается находкой с Трафальгара.
- Омары в бочках против долгоносиков (1813) — один источник.
- «Сухари сушить» — происхождение фразы не подтверждено.
- «Сухарная улица» в Новосибирске — один источник.
- Названия брендов в голос не идут (без рекламы).
