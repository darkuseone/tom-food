## Отброшено
- «Ушаков (1940) назвал солянку неправильной» — источники противоречат друг другу, какое слово помечено «неправ.».
- «Похлёбкин: солянка в Домострое» — vokrugsveta опровергает.
- «Более ста видов солянки» — оценка одного автора.
- Свадебная легенда («устроились») — без источника.
- Политика (кто из политиков любит солянку) — не берём.
