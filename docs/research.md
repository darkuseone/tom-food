# Исследование площадок (собрано 24.10.2026) — выжимка для решений

Метки: **[П]** официально от площадки · **[И]** исследование / большой датасет · **[С]** СМИ / пересказ · **[Б]** маркетинговый блог — проверить.
Площадки канала — YouTube Shorts и TikTok (решение 25.10.2026). Что из этого взято в работу — `docs/episode-formula.md` §«Тест v1».

## Удержание и длина
- Официальных норм удержания нет ни у одной площадки; «viewed 70–80 %, APV ~80 %» — [Б] (subscribr, bytecap). В YouTube Studio есть «Досмотрели / Смахнули» — сравнивать со своими же роликами [П].
- Buffer, 1,1 млн TikTok (март 2025): ролики > 60 с — охват +43,2 %, время просмотра +63,8 % к 30–60 с [И, корреляция].
- Paddy Galloway, 5 400 Shorts / 33 канала: средняя длительность просмотра > 50 с → в среднем 4,1 млн просмотров [С, пересказ digitalinformationworld].
- Todd Sherman (YouTube Shorts, 2023): идеальной длины нет, решает история; «аудитория и есть алгоритм» [С].
- «63 % топ-роликов TikTok цепляют в первые 3 с», «71 % решают за 3 с» — только вторичные пересказы [Б].
- Субтитры: Verizon Media / Publicis 2019 — 69 % смотрят без звука в общественных местах, 80 % чаще досматривают с субтитрами [И, самоотчёт, США]. «+12 % времени у Meta» — не подтверждено [Б].

## Алгоритмы и правила
- YouTube: с 31.03.2025 «просмотр» = каждый запуск/повтор; прежняя метрика — «engaged views» (расширенный режим Studio), YPP считает по ней [П] (Tubefilter 26.03.2025, справка YouTube).
- YouTube YPP, 15.07.2025: «повторяющийся» контент переименован в «неаутентичный» — массовые однотипные ролики с поверхностными отличиями не монетизируются; ИИ можно при оригинальной ценности [П/С] (SEJ, Social Media Today). → наше «не конвейер».
- YouTube, метка синтетики — только для реалистичного контента; анимация освобождена [П] (2024).
- TikTok Newsroom «How TikTok recommends videos #ForYou»: действия зрителя (досмотр, лайки, репосты, комменты), инфо ролика (подпись, звук, хэштеги); подписчики — не прямой фактор; досмотр длинного ролика — сильный сигнал [П]. Репосты/сохранения весят больше лайков — [Б] (Sprout).

## Монетизация
- YouTube YPP: 1 000 подписчиков + 10 млн Shorts-просмотров за 90 дней (или 4 000 ч); автору Shorts — 45 % [П]. Младший уровень (фан-функции): 500 подписчиков, 3 ролика за 90 дней, 3 млн Shorts-просмотров [П].
- TikTok Creator Rewards: 18+, 10 тыс. подписчиков, 100 тыс. просмотров за 30 дней, **ролики > 1 мин**, ограниченный список стран [Б — списки расходятся; доступность для Молдовы проверить в TikTok Studio]. Если доступна — длина > 60 с станет аргументом.

## Сторителлинг и монтаж
- Одна идея на ролик, хук 1–3 с, конец сразу после развязки (без «пока/подпишись»), петля в начало [Б — Habr «100 000 Shorts», мнение]. «MrBeast handbook»: точки повторного вовлечения, первые секунды решают [С, подлинность спорна].
- Темп склеек: данных за «склейку каждые 2–3 с» нет; конф. статья 2026 (Dost & Huang, аннотация) — рост темпа снижал устойчивое вовлечение (говорящие головы) [И, проверить].
- Музыка под голосом −18…−24 дБ [Б]; громкость ≈ −14 LUFS для YouTube, ~−14…−16 для остальных [Б]. Наши 007–008: −20,5 LUFS (замер 25.10.2026).
- В ленте обложку почти не видно — решает первый кадр; обложка — для профиля/поиска.

## Примеры
- Zack D. Films (анимация + голос + один факт): №1 в мире по Tubefilter, неделя 5–11.10.2026 — 1,4 млрд просмотров за неделю, 29 млн подписчиков [С].
- Jeanelle Eats: 3 Shorts/день → +600 тыс. подписчиков, 50–100 млн просмотров/мес [С, Tubefilter 2022]. Feel Good Foodie — 1 млн через Shorts [П, blog.youtube].
