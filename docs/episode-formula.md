# Формула ролика про блюдо (v0)

> **хук-шок про блюдо (0–2 с) → бренд-фраза + укус (≤ 1,2 с) → 6–9 «остановок» истории (страна/эпоха/кто/что добавили/как переименовали) → блюдо сегодня (аппетитно) → кнопка ≤ 2 с с петлёй в хук.**

Длина 50–70 с (ровно 60 не нужно). Остановка = один факт-панчлайн, реплика ≤ 14 слов, 4–7 с.

## Что обязательно в каждом ролике
1. **Страна и момент рождения** (или спор о нём — честно: «версий три»).
2. **Имя:** как называлось раньше / почему так называется / кто ошибается в названии — если есть поворот.
3. **Состав сквозь века:** что добавили, что выкинули (помидор в Европе после XVI в., картошка, сахар, майонез…) — на HUD-списке.
4. **Сегодня:** как выглядит и сколько едят (цифра), аппетитный кадр.
5. **Сквозной предмет или персонаж** (ложка, котёл, один и тот же рецепт-листок) — связывает остановки.

## Меню вариаций (каждый ролик берёт другое; вести учёт в `docs/dishes.md`)
- **Хук:** «вы всё время ошибались» (Цезарь — не Юлий) · шок-цифра · невозможная картинка (картошка фри… из Бельгии в окопах?) · вопрос-загадка («почему оливье без оливье?») · суд/спор стран.
- **Структура:** рецепт сквозь века (ингредиенты зачёркиваются) · «три страны спорят» (суд, Том — судья) · «блюдо-путешественник» (по карте) · обратная (от сегодняшней тарелки вглубь) · «имя-обманщик» · «одно блюдо — пять ошибок о нём».
- **Финальная фраза перед кнопкой** — каждый раз новая, петля к хуку.
- **Переходы** — свой набор на ролик, без повторов внутри ролика (каталог — `ref-style.md` + кухонные из `channel.md`).

## Удержание (перенесено из статистики ТОМ-ТУР, `lessons.md`)
- 0,0–0,5 с: движение + звук (шкворчание, хруст) с первого кадра; блюдо крупно в центре; текст-хук ≤ 3 слов.
- Первое слово — шок-слово. Бренд-фраза ≤ 1,2 с. Кнопка ≤ 2 с. Прогресс на экране (список ингредиентов растёт).

## Факты
- 20–30 кандидатов из 2+ источников (food historians, энциклопедии, музеи еды, Oxford Companion to Food, научпоп), отбор 6–9 сильнейших. Источники — `docs/sources/<эп>.md`.
- Мифы о происхождении блюд — **частая ловушка**: многие «красивые легенды» (Мария-Антуанетта, Марко Поло и макароны, граф Сэндвич…) — либо неподтверждены, либо выдуманы. Это и есть материал для хука «вы ошибались», но формулировать честно: «легенда», «версия», «документов нет».
