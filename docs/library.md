# Библиотека (автоиндекс, `python3 tools/libindex.py`) — читать ВМЕСТО файлов

## lib/ — общий код канала (подключён в каждом выпуске: функции и костюмы вызываются напрямую)

### direct.js
Режиссура 002 — общий каркас. Конкретику каждой сцены задают миры через DIR[name] (см. scenes.js):

- `grade(name, o2)` — цветокор на итоговом кадре: насыщенность (SAT из scenes.js, с 004 — 1.1) + тон + виньетка
- `coverHud()` — раскладка под сетку профиля: всё важное в центральной полосе 3:4 (y 240–1680)
