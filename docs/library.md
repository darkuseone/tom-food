# Библиотека (автоиндекс, `python3 tools/libindex.py`) — читать ВМЕСТО файлов

## lib/ — общий код канала (подключён в каждом выпуске: функции и костюмы вызываются напрямую)

### direct.js
Режиссура 002 — общий каркас. Конкретику каждой сцены задают миры через DIR[name] (см. scenes.js):

- `grade(name, o2)` — цветокор на итоговом кадре: насыщенность (SAT из scenes.js, с 004 — 1.1) + тон + виньетка
- `coverHud()` — раскладка под сетку профиля: всё важное в центральной полосе 3:4 (y 240–1680)

### food_001.js
«ТОМ НА ВКУС» — общие съедобные детали и люди эпохи (кандидат в engine/food.js после 001).

- `leaf(x, y, s, rot = 0, o = {})` — лист ромэна: волнистый край, светлая жилка, прожилки
- `crouton(x, y, s, rot = 0, o = {})` — гренка: кубик с поджаристыми гранями и порами
- `parmWedge(x, y, s, rot = 0)` — клин пармезана: корка, зерно
- `wBottle(x, y, s, rot = 0, o = {})` — бутылка вустерского соуса: оранжевая этикетка, бумажная обёртка
- `anchovy(x, y, s, rot = 0, o = {})` — анчоус: серебристая спинка, глаз (может подмигнуть)
- `woodBowl(x, y, w, h, o = {})` — деревянная салатница: обод, кольца древесины (рисовать back/front отдельно)
- `plateCaesar(x, y, s, t, o = {})` — классическая тарелка: целые листья веером, гренки, стружка, соус с бликами
- `hat20(x, y, s, kind, col = '#3a3028', flip = 1)` — шляпы поверх human(): x,y — ноги персонажа, s — его масштаб
- `crumbs(x, y, t, t0, n = 14, seed = 7, col = FD.crout)` — крошки разлетаются после t0
- `bubbleTag(s, x, y, t, t0, col = '#d9482b', size = 48, rot = )` — всплывающий «ценник» в мире
- PROPS (pose.prop): fork, croutonP, leafP, tray, megaphone
