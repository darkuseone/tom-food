Правило отбора: в каждом блюде должен быть поворот (имя, состав, страна или разоблачённая легенда). Чередовать «наши» (оливье, борщ, пельмени) и мировые.

**Рекомендую первым — Салат Цезарь**: узнаваемо везде, хук «Юлий Цезарь его не ел» мгновенный, есть сухой закон, Голливуд и спор братьев — много поворотов на 60 с.

## Учёт вариаций 001
- Укус: хруст гренки. Том-малыш: в салатнице. Переходы: трещина-гренка, пыль, двери, ныряние в миску, лист, капли соуса, волна соуса, винт, хлопушка, тарелка, клош. Палитра: помпейский красный → пыльная охра → тёплый бар → кафель → дерево → нуар → небо → павильон → салон → нержавейка → неон.

## Учёт вариаций 002
- Укус: хруст панировки (nugget_bite), переход — гигантский укус съедает кадр. Том-малыш: в коробке среди 4 наггетсов-скал. Переходы: укус · мясорубка-полоски · желток · дверь морозилки · конверт · пузыри фритюра · луковое кольцо · клапаны коробки · удар молотка (сплющивание) · вспышка-диафрагма · мазок соуса. Палитра: изумрудный аукцион → мятная лаборатория → ночь под лампой → голубой иней → сепия почты → неон бургерной 70-х → медь тест-кухни → закат золотой лихорадки → томатный картон → грозовой суд → тёплая студия. Костюмы: смокинг · лаборант · почтальон · повар закусочной · шеф · старатель · адвокат.

## Учёт вариаций 003
- Укус: вилка входит в слои шубы (fork_squish), переход — вилка протыкает кадр 4 прорезями. Том-малыш: в разрезе шубы, катается на майонезной волне. Переходы: вилка-прорези · свекольный сок снизу · рулон плаката · ящик картотеки · гравюра-сепия → цвет · подушка-перья · иней · майонезная сетка · ёлочный шар · снежок. Палитра: новогодний красно-зелёный → сепия трактира → агит-красный → серый архив → кирпич Англии → ночной синий → бирюза 60-х → свекольный разрез → гирлянды. Костюмы: свитер+колпак · половой · агитатор · сыщик · викторианец · пижама · хозяйка в косынке.

## Учёт вариаций 004
- Укус: вилка в дрожащее желе (fork_squish + jelly_wobble). Том-малыш: в кастрюле среди костей. Переходы: желейная волна · вертел · свиток · салфетка-гармошка · сдёрнутая скатерть · колокольчик · лопнувший пузырь · дверь холодильника · зеркало ложки · снег с крыши. Палитра: фиолетовая TV-студия → видеозвонок → французская кухня 1375 → терем → север/юг → голландский зал → барская кухня → янтарь кастрюли → кухня 80-х → карта → зимняя дача. Костюмы: адвокат · повар-средневековье (cotte + chaperon) · князь · голландец · тулуп · хозяйка · шеф.
