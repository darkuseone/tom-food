Правило отбора: в каждом блюде должен быть поворот (имя, состав, страна или разоблачённая легенда). Чередовать «наши» (оливье, борщ, пельмени) и мировые.

**Рекомендую первым — Салат Цезарь**: узнаваемо везде, хук «Юлий Цезарь его не ел» мгновенный, есть сухой закон, Голливуд и спор братьев — много поворотов на 60 с.

## Учёт вариаций 001
- Укус: хруст гренки. Том-малыш: в салатнице. Переходы: трещина-гренка, пыль, двери, ныряние в миску, лист, капли соуса, волна соуса, винт, хлопушка, тарелка, клош. Палитра: помпейский красный → пыльная охра → тёплый бар → кафель → дерево → нуар → небо → павильон → салон → нержавейка → неон.
- 002: укус — хруст солёного огурчика (брызги рассола). Том-малыш: на странице «Нашей пищи» 1894 среди гигантских рябчика, рака и оливки. Переходы: брызги рассола, крышка банки, нож шинкует кубиком, ложка-водоворот, переворот сковороды, пар из котла, сдёрнутая скатерть, скалка, скорлупа по зигзагу, отражение в ложке. Палитра: ночная кухня с гирляндой → оливковая кухня 70-х → гастроном → ар-деко красно-золотой → кафель с медью → пергамент → зелёный шёлк «Эрмитажа» → тёмный архив → парижский кирпич с медью → кирпичное кафе. Костюмы: худи «Т» + фартук → советский костюм + фартук → повар → фрак + фартук → сюртук конторщика + фартук.
