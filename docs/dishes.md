Правило отбора: в каждом блюде должен быть поворот (имя, состав, страна или разоблачённая легенда). Чередовать «наши» (оливье, борщ, пельмени) и мировые.

**Рекомендую первым — Салат Цезарь**: узнаваемо везде, хук «Юлий Цезарь его не ел» мгновенный, есть сухой закон, Голливуд и спор братьев — много поворотов на 60 с.

## Учёт вариаций 001
- Укус: хруст гренки. Том-малыш: в салатнице. Переходы: трещина-гренка, пыль, двери, ныряние в миску, лист, капли соуса, волна соуса, винт, хлопушка, тарелка, клош. Палитра: помпейский красный → пыльная охра → тёплый бар → кафель → дерево → нуар → небо → павильон → салон → нержавейка → неон.

## Учёт вариаций 002
- Укус: хруст фри (излом кадра пополам). Том-малыш: внутри корзины фритюра (frietkot). Переходы: фри ломается, сковорода дном, нож-брусочки, кулёк-воронка, тонет в жире, пар → дым, блин-переворот, дверь морозилки, лавина фри, кассовый чек, майонезная спираль. Палитра: дуб суда → зимний Маас → пыльно-розовый Париж → ярмарочные сумерки → золото фритюра → хаки окопа → кирпич кухни → небо Айдахо → кафель фастфуда → холодный суд 2002 → закат порта. Сквозной предмет: судейский молоток (хук → кнопка). Трофей фартука №2: капли кетчупа и майонеза.
