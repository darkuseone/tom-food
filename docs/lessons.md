# Уроки ТОМ-ТУР (перенесено 19.10.2026)

## Статистика (TikTok, 001–002)
- 002 Москва: 102 тыс. просмотров, ср. удержание 53 %, досмотр 14,8 %, 641 подписка, 744 комментария. 001 Нью-Йорк: 10 тыс., 41 %.
- Главная потеря — **0:01–0:02**: первый кадр почти статичен, мультяшность считывается как детское, ударное слово звучит поздно.
- Вторая — связка «Не веришь? Отматываем время!» (2–3 с без факта). Обрыв на длинной кнопке (3,5 с).
- Близкое аудитории держит лучше (Москва > Нью-Йорк) → для блюд чередовать «наши» и мировые.
- Реалистичные цели: удержание 3 с ≥ 85 %, среднее ≥ 55 %, досмотр ≥ 20 %.

## Правила владельца (действуют и для нового канала)
- Взрослая аудитория, не детский мульт; шутки сухие, без пошлости и политики.
- Только проверенные факты, источник на каждый; спорное — «почти», «версия», или другой факт.
- Без воды: в каждой реплике цифра/имя/деталь; повороты «но… / а потом…».
- Понятно обычному зрителю: никаких терминов без перевода на простой язык.
- Не конвейер: свой хук, структура, переходы, палитра, костюмы, финальная фраза на каждый ролик; вести учёт.
- Каждый ролик рисуется с нуля, задники детальные (3–4 плана, люди с руками и мимикой), на рисовании не экономить.
- Переходы физические, не «листание страниц»; внутри ролика не повторять.
- Цветастее: `SAT = 1.1`. Шёпот запрещён. Ударения U+0301, «ё». Ровная громкость (mean ≈ −20, пик ≤ −1 дБ).
- Длина 50–70 с (ровно 60 не нужно, сильный факт важнее).
- Переименования/старые имена — брать, если есть поворот; голый список — вода.
- Обложка = первый кадр ролика + отдельный cover.png; всё важное в полосе y 240–1680.
- Тексты выкладки — в конце сдачи, колонкой без подписей: TikTok, потом YouTube Shorts.
- Английская версия — только по запросу. Голоса NIKITA, NIKITA2, Cartman — не трогать никогда.
- Экономия: один агент по очереди; субагенты — 1–2 и только на большие независимые куски (sonnet); не читать большие файлы движка (есть `ref-api.md`).
- Экономия ElevenLabs: звуки из CATALOG, `est.py` до озвучки, музыка 20 с.
