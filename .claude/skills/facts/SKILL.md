# Факты → сценарий → lines.json

## Поиск (экономно, ~8–12 вызовов)
- WebSearch `standard` параллельно 2–3 запроса сразу: «<dish> history inventor year», «<dish> origin myth legend debunked», «<dish> name etymology / today sales statistics».
- WebFetch только 3–4 лучших страниц (Wikipedia EN, Smithsonian/History.com/Britannica/NatGeo, официальный сайт компании, Snopes/Guinness для рекордов) с промптом «Extract all facts with dates/numbers: …» — перечислить, что нужно.
- Факт идёт в ролик только при 2+ независимых источниках. Один источник или цифры противоречат → «Отброшено» в sources (так было в 002: порода Mr. McDonald, годовые продажи). Легенды — словами «версия / легенда / по словам …».
- Россию не упоминать; «сегодня» — по миру с цифрой. Без политики реальных людей; спорные «национальные» блюда — только версии.

## Структура (не конвейер — сверить docs/dishes.md, docs/episode-formula.md)
- Взять ДРУГОЙ тип хука и структуру, чем в прошлых выпусках (001 — «вы ошибались» + имя-обманщик; 002 — шок-цифра + изобретение-детектив с петлёй).
- Обязательно: страна и момент рождения · имя (если есть поворот) · состав сквозь века (→ RECIPE) · сегодня с цифрой · финальная фраза-петля к хуку · сквозной предмет/персонаж.
- 10–11 реплик: h1 (шок-слово первым, ≤ 3 с) · h2 «Откусим историю!» · 8–9 остановок · t1 сегодня · x1 «Пиши блюдо — откусим!». Реплика ≤ 14 слов, цифра/имя/деталь, панчлайн в конце, повороты «но… / а потом…».

## Файлы
- `docs/sources/<эп>.md`: таблица «факт | источники» + «Отброшено: …».
- `episodes/<эп>/script.md`: шапка (хук · структура · длина · укус · Том-малыш · карта), таблица «сцена | реплика | картинка/Том | переход В сцену», строки «Карточка рецепта / Костюмы / Палитра». Переходы — кухонные, физические, не из прошлых выпусков.
- `lines.json`: теги эмоций в начале ([shocked, loud], [dramatic], [sly], [dry], [excited], [proud], [playful, to the camera]…), можно второй тег внутри реплики; шёпот запрещён; U+0301 после ударной гласной во ВСЕХ словах 2+ слогов; «ё»; числа словами («Шестьдеся́т тре́тий год»).
- `python3 tools/est.py <эп>` (нужен episode.json — создаёт new_episode.py) → цель 55–64 с; длиннее — резать текст ДО озвучки (кредиты).
- Сценарий владельцу: SendUserFile `episodes/<эп>/script.md` + 3 строки (хук, структура, длина).
