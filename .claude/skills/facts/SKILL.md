# Факты → сценарий → lines.json

## Поиск (~8–10 вызовов)
- Параллельно: WebFetch Wikipedia RU + EN по блюду («извлеки все факты с датами: происхождение, легенды и опровержения, первое упоминание, состав, аналоги в других странах, рекорды/цифры»), WebSearch «<блюдо> легенда миф история» и «<dish> origin history». Потом 2–3 WebFetch лучших статей (Вокруг света, Smithsonian, History.com, Atlas Obscura, Snopes/Guinness).
- Факт в ролик — только 2+ независимых источника. Один источник/противоречие → «Отброшено». Легенды — «легенда / версия / по словам».
- Россию отдельно не упоминать («сегодня» — по миру/«у нас» с цифрой; СССР — только как место рождения, если это история блюда). Без политики реальных людей; спорные «национальные» блюда — версии.

## Структура (не конвейер)
- Тип хука и структура — НЕ как в прошлых выпусках (`tail -20 docs/dishes.md`). Меню: «вы ошибались», шок-цифра, вопрос-загадка, невозможная картинка, суд стран; структуры: имя-обманщик, изобретение-детектив, археология по слоям, блюдо-путешественник по карте, обратная, «5 ошибок».
- Обязательно: страна и момент рождения · имя (если поворот) · состав сквозь века (→ RECIPE) · сегодня с цифрой · финальная фраза-петля к хуку.
- 11–12 реплик: h1 (шок-слово первым, ≤ 2,5 с) · h2 «Откусим историю!» · 8–9 остановок · t1 сегодня · x1 «Пиши блюдо — откусим!». ≤ 14 слов, цифра/имя/деталь, панчлайн в конце.
- **С 009 — тест v1** (`docs/episode-formula.md` §«Тест v1»): h1 — открытая петля (вопрос, ответ только в развязке) · **≤ 7 остановок**, одна идея · 2–3 поворота «но…» (↻ в script.md) · развязка ★ на 75–85 % · t1 — сегодня + цифра → вопрос-выбор «А или Б?» · 1–2 немые паузы-гэга (`timeline.beats` в episode.json) · длина 54–62 с без воды.

## Озвучка: ударения и произношение (ElevenLabs v4) — субтитры НЕ трогаются
- Ударение U+0301 после ударной гласной во ВСЕХ словах 2+ слогов; «ё» вместо «е». Внимательно с омографами: «пото́м/по́том», «за́мок/замо́к», «бы́ло», «пла́чу/плачу́».
- Аббревиатуры: в тексте пишем как в субтитрах (США, СССР), произношение подставит `tools/say.json` (США → «сэ-шэ-а́»). Новой аббревиатуры там нет — добавить строку в say.json.
- Числа и всё, что пишется иначе, чем говорится: `{показать|сказать}` — «{1845-м|ты́сяча восемьсо́т со́рок пя́том}», «{McDonald's|Макдо́налдс}». В субтитрах — левая часть, в голос — правая (tools/voicetext.py).
- Теги эмоций в начале ([shocked, loud], [dramatic], [sly], [dry], [excited], [proud], [playful, to the camera]…), можно второй тег внутри; шёпот запрещён.
- `python3 tools/est.py <эп>` — длина + «ПРОВЕРЬ ОЗВУЧКУ» (нет ударения / аббревиатура / цифры). Исправить ВСЁ до `tts.py` — перегенерация стоит кредитов.

## Файлы
- `docs/sources/<эп>.md`: «факт | источники» + «Отброшено: …».
- `episodes/<эп>/script.md`: шапка (хук · структура · длина · укус · Том-малыш), таблица «сцена | реплика | картинка/Том | переход В сцену», строки «Карточка рецепта / Костюмы / Палитра».
- Сценарий владельцу: SendUserFile `script.md` + 3 строки.
