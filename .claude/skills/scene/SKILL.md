# Миры выпуска

API — `docs/ref-api.md` (не читать engine/*.js, tom.js, lib/*.js). Готовое — `docs/library.md`. Шаблон сцены — `templates/w_scene.js` (new_episode.py уже разложил по сценам). Писать каждый мир ЦЕЛИКОМ одним Write; правки — python-replace/sed точечно.

## scenes.js
- `HOOK_LINES` (2 строки ≤ 3 слов), `YR[сцена] = ['год', 'ПОДПИСЬ']` — год и подпись карточки рецепта (пусто у hook/button), `RECIPE = [[строка, WT(k,'слово'), зачеркнуть|null, '?'|'new']]` — видно последние 6.
- `WT(k,'слово')` — начало фрагмента субтитра, `wtw(k,'слово')` — время слова точнее. Слово писать как в субтитре (с пунктуацией: `'курицу!'`, `'«МакФранкенштейном»'`). Субтитры: `grep -o '"words":\[[^]]*\]' episodes/<эп>/data.js`.
- `KEYW.push(...)` — слово-«ценник» (томатная плашка) — 1–2 на сцену.

## Раскладка кадра (ошибки из 002 — сразу так)
- **Безопасная зона (`SAFE = true`, с 009):** плашка канала y ≈ 286, карточка рецепта x 96–470, y 336–700 → туда не ставить табло, меню, доски, словарные карточки (сдвигать в x 500–880). Субтитры y ≈ 1580, центр x 488, ширина ≤ 720. Хук-текст y 360–680 первые 2.6 с. Никакого важного текста при y < 250 и y > 1640, у боков ближе 96 px, а ниже y 900 — правее x 880 (кнопки площадки). На контакт-листе — красная рамка (зона) и оранжевая (кнопки справа).
- **Тест v1 (с 009):** в scenes.js `ENDCARD = false` (нет «ПОДПИШИСЬ») и `LOOP = 0.4` (конец перетекает в первый кадр хука) — ставит new_episode.py. Значит, в `button` Том и камера — близко к позе/кадру хука (тот же x, y, масштаб), иначе стык петли «прыгает»; паузы-гэги (`timeline.beats`) — заполнить реакцией Тома/событием мира. Проверка — `build/<эп>/loop.jpg` после final.sh.
- Том: `x 560–800, y 1700–1780, s 1.1–1.2`, `flip: true` смотрит влево; морда не должна уходить в оранжевую колонку справа. Камера должна держать Тома в кадре: при `cam x` < 500 Том с x > 800 уезжает за край (002: gift, lab, batter — пришлось двигать). Видимая ширина ≈ 1080/(1+z).
- Лапа: `hand:[hx,hy]` локально; мировые координаты ≈ `P.x ∓ hx·P.s` (минус при flip), `P.y + hy·P.s`. Тянуться дальше ~400 px — рука-«шланг», лучше подвинуть предмет.
- Фоновые люди: `human()` s 1.0–1.25 на lay 3–5, иначе выглядят крошками; минимум 2–4 человека с мимикой, реагируют на событие (face: 'shock'/'grin').
- Слои: фон lay 14–30, середина 3–5, стол 1.2–1.6, Том lay 1 (`cat()`), передний план 0.5–0.9. Объект «перед Томом» — рисовать после `cat()` в том же lay(1).
- Предметы с параллаксом на lay 2–6 уезжают при сильном движении камеры — важное (карта, табло) держать ближе к lay 1–2.4.
- Эмоции только из списка: neutral talk shock awe smug sideeye annoyed grin laugh scared cold proud suspicious wink (`squint`, `sweat`, `frost`, `chatter`, `tailUp`, `point`, `walk`, `apron` — параметры позы, не эмоции).

## Еда и костюмы — lib/ (общий код канала, не копировать в выпуск)
- Что уже есть: `grep -n "<слово>" docs/library.md` (функции еды с подписями, PROPS, OUTFIT по файлам) и `docs/ref-costumes.md`. Подходящий по смыслу костюм/реквизит — брать готовый.
- Новое для этого блюда — в `lib/food_<NNN>.js` (функции + `Object.assign(PROPS, {...})`) и `lib/wardrobe_<NNN>.js` (OUTFIT + COST6.<detail> + HAT6.<hat>, `apron: 1`, трофей-пятно на фартуке — обёртка costume5 как в wardrobe_002/003). ## Контроль
- НЕ запускать check.sh/cover.cjs для выпуска, пока идёт его render.sh (пересобирают build/<эп>/film).
- `tools/check.sh <эп> t1 t2 …` (без времён — середины сцен) → Read `build/<эп>/shots/sheet.jpg`. Пачки по 3–4 сцены, кадры: S0+0.05 (переход), события, конец сцены.
- Смотреть: Том в кадре, нет перекрытия карточкой, люди читаются, событие на слове видно, нет пустых полей. 1–2 круга правок на сцену, не больше.
- Ошибка JS → `node tools/dbg.cjs build/<эп>/film <t>`.
