# /episode <блюдо> — выпуск «ТОМ НА ВКУС»

**Экономия контекста:** CLAUDE.md уже в контексте — больше ничего «на всякий случай» не читать. Перед стартом: `tail -30 docs/dishes.md` (что было: хук, структура, переходы, палитра, костюмы — не повторять), `git log --oneline -3`. Движок и миры прошлых выпусков целиком не открывать: API — скил `scene`, готовые детали и костюмы — `docs/library.md` (grep). Этапы — свои скилы, грузить по очереди: `facts` → `scene` → `sound` → `deliver`.

## Планка (владелец, 29.10 и 03.11.2026) — проверяется `tools/qa.py`, рендер только без ⚠
- **Визуал не ниже эталона** 002-olivier, 003-shuba, 002-nuggets: Read `docs/ref/etalon_sheet.jpg` в начале и сверять контакт-листы с ним; перед каждым миром — Read 1–2 мира эталона похожего типа (скил `scene` §«Эталон»).
- **Том крупный, по пояс:** `y ≈ 1580, s ≈ 1.15` при столе на y 1440 (не голова за стойкой); камера после первого ключа в основном `z ≥ 0.22`, центр y 950–1250; уходы на таблички — коротко.
- **Объём рисовки (на всякий случай, как в ТОМ-ТУР):** ≥ 9 миров, каждый ≥ 8,5 КБ, все миры ≥ 100 КБ и ≥ 1350 вызовов рисования (уровень оливье; цель 110 КБ / 1500 — как наггетсы/фри). Не «водой»: объём — это планы, люди с мимикой, утварь эпохи, свет, частицы, анимация по словам.
- **Креатив:** свой тип хука (не как в прошлых 3 выпусках), развязка ★ на 75–85 %, Том-малыш внутри блюда с новым действием, 2 паузы-гэга, у каждой сцены свой физический переход «из материала» сцены, блюдо-герой крупно и аппетитно (пар, блики).
- **Звук:** скил `sound` — SFX на каждое событие картинки и каждый переход, лупы-атмосферы во всех сценах, 2–4 новых звука «фактуры» блюда, −14 LUFS.
- **Плашка «ПОДПИШИСЬ»** в конце обязательна (`ENDCARD = true`, ставит new_episode.py; тает перед петлёй).

## Порядок (~2 ч)
0. **Старт:** `git checkout main && git pull origin main && git checkout -b episode-<NNN-блюдо>` (если сессия задала свою ветку — работать в ней). Номер — следующий после последнего в `docs/dishes.md`.
1. **Факты и сценарий** — скил `facts` → `docs/sources/<эп>.md`, `script.md`, `lines.json`, `tools/est.py` (54–62 с, ≤ 7 остановок). Сценарий владельцу и «ок» — только если он не сказал «делай сам» и это не очередь/неделя.
2. **Заготовка:** `python3 tools/new_episode.py <NNN-блюдо> "<Блюдо>" hook,<сцены>,today` — выпуск + `lib/food_<NNN>.js`, `lib/wardrobe_<NNN>.js`; вся еда и все костюмы прошлых выпусков уже подключены.
3. **Озвучка:** `python3 tools/tts.py lines <эп>` → `python3 tools/prep_voice.py <эп>` → `episode.json` (hook, beats на паузы-гэги) → `python3 tools/build_data.py <эп>`.
4. **Миры** — скил `scene` (костюмы можно отдать 1 агенту-помощнику: бриф как в `docs/ref-costumes.md`). Контакт-лист `bash tools/check.sh <эп> t1 t2 …` по 2 круга на сцену; `check.sh` печатает worldstat и qa.
5. **Обложка:** `w_cover.js` → `node tools/cover.cjs <эп>` → Read. Блюдо — герой, Том крупно, 2 строки, плашка — имя блюда.
6. **Звук** — скил `sound`.
7. **Ворота:** `python3 tools/qa.py <эп>` — всё ✓, контакт-лист рядом с `docs/ref/etalon_sheet.jpg` — не хуже. Только потом рендер.
8. **Рендер и сдача** — скил `deliver`. Коммит + push после каждого большого шага (сессию могут перезапустить).
