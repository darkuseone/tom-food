# 021 — Сырники (правила v1 + сценарий-цепочка + ПОДПИШИСЬ + планка 14.11)

Хук — **парадокс «вы ошибались» / невозможная картинка**: Том держит сырник и брусок твёрдого сыра: «В сырниках нет ни грамма сыра. Так почему они — СЫРники?» → ответ ★ в s12 (~75 %).
Структура — **«ищем сыр» — следствие по одному слову, прямая хронология** (1380 → Масленица → 1550-е → XIX в. → советские 50-е → ★ → сегодня). Сквозной приём — **сыр-«самозванец»**: брусок жёлтого твёрдого сыра с дырками в каждом мире «примеряет» табличку «СЫР», а в развязке Том срывает её и вешает на творог. На экране счёт «СЫР? 0» в каждой остановке.
≈ 75 с · укус: Том в бабушкиной утренней кухне на даче откусывает горячий сырник со сметаной — корочка хрустит, пар · Том-малыш: в соломенной шляпе и с ложкой-шестом сплавляется по сметанной реке на гигантской сковороде среди сырников-островов, карабкается на сырник-гору, вязнет в варенье, втыкает табличку «СЫР = ТВОРОГ».

Карточка рецепта (прямая хронология, дописывается/зачёркивается): 1380 «кислый „сыр“ (творог)» → Масленица «+ сметана · масло» → 1550-е «блин + сыр (творог) + яйца» → XIX в. «варёные, в воде» → 1866 «твёрдый сыр?» (зачёркнут) → 1950-е «творожники?» (зачёркнут) → сегодня «творог · яйцо · мука · сахар · сметана».
Костюмы: дачный халат + фартук (новый) · новгородский писец (новый) · тулуп масленицы · боярский повар в кафтане (новый) · кухарка XIX в. в чепце (новый) · сыровар в фуражке (новый) · повар столовой 50-х (chef/стол.) · Том-малыш в соломенной шляпе-плотовщике (новый) · дачный халат.
Палитра: розовый рассвет дачной кухни, сливочный и медовый → серебристо-берёзовый Новгород с синей рекой → красно-снежная Масленица → синие сумерки поста → тёмно-золотой терем при свече → медно-зелёная кухня XIX в. → сырно-жёлтая сыроварня с белым светом окна → кафель столовой 50-х, мятный и красный → сливочно-золотая сковорода (микромир) → солнечная дачная кухня.
Пауза-гэги: Том поводит ухом на «кот без клички» (domo), паспорт-сырник падает Тому-малышу на голову (syrnik).
Финал: «Подпишись — откусим ещё одно имя!» (новая).

Критик (§9): хук с предметом (сыр/сырник) и вопросом ✓ · ответ ★ на ~75 % ✓ · миф зрителя (в «сырниках» должен быть сыр; «правильно — творожники») ✓ · связки «но / а / тот же / поэтому / а раз» между всеми ✓ · повторный хук каждая остановка («что за сыры?», «а потом…», «подвох», «разгадка? нет») ✓ · поворот «слова творог нет» на ~42 % + шутка «кот без клички» ✓ · число-сувенир 470 лет ✓ · шутки: кот без клички, пельмень, паспорт ✓ · без терминов (береста → «берестяная записка», Домострой → «при Иване Грозном») ✓ · финал-петля + «сырники или творожники?» ✓ → **9/10** (минус: s9 «понесёт» — прошедшее-будущее, разговорно; ★ на 75 % — нижняя граница).
Прочтение без картинки: «Ещё загадка» → заменено на «Тот же «сыр» — и в Масленице» (было «и ещё»); «на бересте» → «в берестяной записке» (понятнее); «И вот первые сырники» → «А сырники? Впервые…» (связка-вопрос); «Поэтому советские книги» → «А раз сыра в них нет» (логика). Длина est ≈ 78 с.
