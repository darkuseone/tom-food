# 022 — Докторская колбаса (правила v1 + сценарий-цепочка + ПОДПИШИСЬ + планка 14.11)

Хук — **знакомая еда + странный факт / загадка-диагноз**: Том-врач в поликлинике выписывает рецепт на колбасу: «Эту колбасу прописывали больным. От какой болезни? Спорим — не угадаешь!» → ответ ★ в s12 (≈ 78 %): диагноз из документа 1936 г. — «подорванное здоровье в результате Гражданской войны… и царского деспотизма».
Структура — **«история болезни»**: HUD — медкарта/рецептурный бланк (карточка рецепта = «Rp.:»), остановки — графы карты: назначение 1936 → рецептура → производство → «осложнения» 70-х (крахмал) → ГОСТ-79 (буйвол и як, Том-малыш осматривает срез) → быт: слух о бумаге, ценник 2,20, «колбасная электричка» → ★ диагноз → сегодня (40 марок, бумаги 0, знак качества 9) → «А или Б?».
≈ 79 с · укус: Том-врач откусывает бутерброд с толстым кружком «Докторской» прямо над рецептурным бланком · Том-малыш: в докторской шапочке со стетоскопом «осматривает» срез гигантской колбасы — слушает розовый «мрамор», находит зерно крахмала, из-за оболочки-стены выглядывает як, сверху опускается нож-гильотина (пауза-гэг).

Карточка рецепта («Rp.:», дописывается/зачёркивается): 1936 «свинина 85 % · говядина 15 % · соль · сахар · кардамон» → 1970-е «+ крахмал 2 %» → 1979 «буйвол? як?» → сегодня «свинина · говядина · яйцо · молоко».
Костюмы: врач поликлиники (новый docA + шапочка) · учёный-технолог 30-х в халате и круглых очках (labA) · рабочий мясокомбината в колпаке (новый) · технолог 70-х в синем халате (новый) · Том-малыш-доктор · покупатель в кепке с авоськой (новый) · пассажир электрички в ушанке (новый) · архивариус в нарукавниках (новый) · домашний (сегодня).
Палитра: мятно-голубой кафель поликлиники с тёплой лампой → охристая лаборатория 30-х → белый пар мясокомбината с медью → серо-синий тусклый цех 70-х → розовый «мрамор» колбасы (микромир) → жёлтый тёплый гастроном → зимняя синяя электричка с зелёным вагоном → тёмный архив с зелёной лампой → солнечная утренняя кухня.
Пауза-гэги: як выглядывает и жуёт, нож-гильотина «ХРЯСЬ» рядом с Томом-малышом (sausage); Том-архивариус отставляет колбасу «от царизма» с серьёзным лицом (archive).
Финал: «Подпишись — выпишу рецепт на следующую!» (новая).

Критик (§9): хук с предметом (колбаса/рецепт) и вопросом ✓ · ответ ★ ≈ 78 % ✓ · миф зрителя («докторская — для врачей/просто полезная») назван в s3 ✓ · связки «поэтому / и / но / а / зато / отсюда / так» ✓ · повторный хук: «но каких — не поверишь», «но в 70-х…», «…и яка», слух о бумаге (закрыт в t1), «осталось найти», «так от чего лечили?» ✓ · поворот на ≈ 35–45 % (крахмал → буйвол и як) + шутка «яка не прописывал ни один врач» ✓ · число-сувенир «2,20» и «9 из 40» ✓ · шутки: як, «осталось найти», загадка-электричка, «от царя лечат колбасой» ✓ · без терминов (ВНИИМП → «мясной институт», ГОСТ — общеизвестно) ✓ · финал-петля + «жаришь или на бутерброд?» ✓ → **9/10** (минус: два числа-сувенира конкурируют; s9→s10 связка неявная).
