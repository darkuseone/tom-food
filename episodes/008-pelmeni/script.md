# 008 Пельмени — сценарий (54 с)

Хук: «Ты ешь хлебные уши! Так переводится слово „пельмени“» (перевод-сюрприз). Структура — **викторина «правда / миф / версия»**: на каждое утверждение Том-ведущий ставит штамп.
Том-малыш — внутри пельменя, в начинке «три мяса». Финал — вопрос в камеру «сколько хлебных ушей съешь за раз?» → «Пиши блюдо — откусим!».
