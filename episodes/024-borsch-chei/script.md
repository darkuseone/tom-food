# 024 — Чей борщ? (правила v1 + сценарий-цепочка + планка 14.11 + правки 17.11)

Хук — **спор соседей + загадка «ответ на дне тарелки»** (дословно с фразы владельца «Чей борщ?»). ВАУ-первый кадр: тарелка красного борща крупно сверху — пар, сметанная спираль, капли жира-«золотинки», укроп; Том над ней с ложкой; на h2 — укус, резкий наезд и **нырок в тарелку** (камера проваливается в сметанную спираль, красная толща, пузырьки).
Структура — **«на дно тарелки»: археология рецепта по слоям** (не путь по карте, как в 005): каждая сцена — слой борща/эпоха, лента ингредиентов слева дописывается и зачёркивается; ответ ★ на s10 (≈ 78 %).
≈ 65 с (est) · укус: ложка борща со сметаной → нырок в тарелку · Том-малыш: внутри кастрюли XIX в. — прыгает по гигантским кубикам картошки, как по кочкам, и пинком выкидывает репу за борт (пауза-гэг «Репа, ты уволена!» — табличка УВОЛЕНА). Факты — `docs/sources/024-borsch-chei.md`.

Костюмы: худи + фартук (хук) · льняная рубаха (новый linenA) · купец-немец в берете (merchA, 023) · вышиванка (новый vyshA) · Том-малыш в фартуке-поварёнке · повар 1920-х в колпаке · свитер с оленями (готовый) · молдавская кэчула + безрукавка (новый) · вышиванка (answer) · домашний (сегодня).
Палитра: тёплый рубиновый крупный план с золотом жира → росисто-зелёный луг на рассвете → янтарно-синие сумерки над рекой → рубиново-охристая хата с печью → красное «озеро» в кастрюле с белым паром → мятно-кремовая эмаль 1920-х с томатным красным → синий снег Сочельника | розовый праздник → золотая осень виноградника → солнечно-жёлтый сад с подсолнухами → вечерняя кухня с лампой.
Пауза-гэги: никто не покупает борщ у Тома-купца — ест сам (kyiv, 0,7 с); репа с табличкой «УВОЛЕНА» вылетает из кастрюли (pot, 0,6 с).
Финал: «Пиши в комменты — откусим!» (новая).

Критик (§9): хук с предметом («тарелка», «дно») и вопросом «чей?» ✓ · ответ ★ ≈ 78 % ✓ · миф зрителя (спор «наш!») назван ✓ · связки «но / запомни / но / и тогда / но / а соседи / а в Молдове / так» ✓ · повторный хук: «запомни: кисло», «каждый варит свой», «краснеет!», «уволена», «выгнал святое», «три тонны», «свёкла не нужна!» ✓ · поворот + шутка на 28–45 % («Репа, ты уволена!», «наглее всех помидор») ✓ · число-сувенир «3 тонны кефира» (+ «тысяча лет», «XVI век») ✓ · шутки 3 ✓ · без терминов (борш объяснён «квас из отрубей») ✓ · финал-петля + «свежий или вчерашний?» ✓ → **8,7/10** (минус: число-сувенир — про литовский, а не про «главный» борщ; s1–s9 — короткие эпохи, вероятен «список» без связок — закрыто «запомни: кисло» → «выгнал святое — квас» → «лишь бы кисло»).
Прочтение без картинки (исправлено): «Соседи спорят веками» → «до хрипоты» (веками — неправда, спор новый); «первое упоминание» → просто «немецкий купец» (трактовки расходятся); «1584-й» вслух → «XVI век» (длинное число съедало 2 с, год — на плашке); «свёклу квасят» — убрано ради длины, кислинку несёт «святое — квас»; «настоявшийся» → «вчерашний» (короче, понятно). Длина est ≈ 66,8 → после озвучки ужать паузы/темп до ≤ 65 с.
