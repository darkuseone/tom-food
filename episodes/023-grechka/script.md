# 023 — Гречка (правила v1 + сценарий-цепочка + ПОДПИШИСЬ + планка 14.11)

Хук — **опровержение мифа + загадка-родня**: Том-пасечник посреди цветущего поля гречихи откусывает ложку каши из чугунка: «Гречка — вовсе не злак! А её родня — у тебя на грядке. Угадаешь, кто?» (на заднем плане, незаметно, — грядка со щавелем и ревенем у забора: ответ всё время в кадре). Ответ ★ в s14 (≈ 77 %): гречиха — из семьи гречишных, её родня — щавель и ревень, «зерно» — плод-орешек.
Структура — **«путь зерна» по карте** (не флажки 019, а дорожка из рассыпанных зёрен по пергаментной карте — она «прорастает» от сцены к сцене): Юньнань у Гималаев → через Тибет и степи на запад → греки и Византия (имя «гречка», версия) → Европа: сарацинская, языческая, «буковая» (подсказка-бук) → русская печь: «матушка наша», цвет от огня → ★ зерно-пирамида крупно (Том-малыш) → «чёрная каша» на чёрный день → ★ гербарий ботаника → сегодня + «А или Б?».
≈ 78 с (est) · укус: Том-пасечник откусывает ложку рассыпчатой каши — зёрна сыплются, пчела садится на ложку · Том-малыш: альпинист с ложкой-ледорубом взбирается по гигантским трёхгранным зёрнам-пирамидам в кипящем чугунке (пар, пузыри, масло-солнце); пауза-гэг — зерно под ним переворачивается, и он съезжает по грани, как с горки, в лужу масла «ПЛЮХ». Карточка рецепта («паспорт гречки», дописывается): родина — горы Юньнань → имя — «гречка» (греки) / сарацинская / языческая / buckwheat → цвет — зелёная → коричневая (огонь) → зерно — три грани → семья: ~~злаки~~ → гречишные ✓ (щавель, ревень).
Костюмы: пасечник в шляпе с сеткой (новый beeA) · горец Юньнани в бамбуковой шляпе с корзиной (новый yunA) · греческий монах в рясе и скуфье (новый monkG) · средневековый торговец в берете (новый merchA) · рубаха (rubakha) · Том-малыш-альпинист (новый alpA) · покупатель в куртке (новый shopA) · ботаник (botanist) · домашний (сегодня).
Палитра: золотисто-розовый закат над бело-розовым полем → нефритово-голубые туманные террасы с белыми пиками → лазурь и золото Византии у реки → кирпично-красный рынок с витражом → тёмное дерево избы с оранжевым огнём печи → коричнево-золотой микромир в чугунке с белым паром → холодный люминесцентный магазин с чёрной тучей → тёмно-зелёный кабинет ботаника с латунной лампой → солнечная утренняя кухня.
Пауза-гэги: Том-малыш съезжает по грани зерна в масло «ПЛЮХ» (grain); Том-ботаник откусывает лист щавеля и морщится — кисло (botany).
Финал: «Подпишись — разберём следующее по зёрнышку!» (новая).
Сквозной приём: щавель и ревень «прячутся» в каждом мире (грядка в хуке, ревень на склоне Юньнани, пучок щавеля у торговки, ревень на подоконнике избы…) — ответ всё время в кадре; дорожка зёрен на карте.

Критик (§9): хук с предметом и вопросом «угадаешь, кто?» ✓ · ответ ★ ≈ 77 % ✓ · миф зрителя («гречка — крупа/злак, как пшеница») назван в хуке ✓ · связки «но / поэтому / и так везде / а у нас / и / так» ✓ · повторный хук: «но ей тесно», «по версии», «своей не признаёт никто», «запомни бук!», «без обжарки — зелёная!», «у пшеницы таких нет», «чёрный день», «если не злак?» ✓ · поворот + шутка на ≈ 30–37 % (имена-чужаки; «своей её не признаёт никто») — чуть раньше 40 %, но вторая волна (печь/зелёная) на 42–50 % ✓ · число-сувенир «≈ 2 млн т, половина у нас» + «без обжарки — зелёная» ✓ · шутки: «своей не признаёт никто», «чёрная каша — на чёрный день», «ешь родню щавеля с котлетой» ✓ · без терминов (гречишные объяснены щавелем) ✓ · финал-петля + «с молоком или с котлетой?» ✓ → **8,8/10** (минус: число-сувенир «2 млн т» слабее, чем факт про зелёную гречку; связка s9→s10 «и» — по смыслу «улика», не причина).
Прочтение без картинки (исправлено): «гречка — не крупа» → «не злак» (крупа — это продукт, гречневая крупа — честно крупа; «не злак» — правда); «Зато Европа зовёт её чужим именем» → «И так везде» (мы тоже назвали её по чужакам — греками, поэтому «так везде»); «Каждый валит на чужаков» → «Своей её не признаёт никто!» (очеловечивание, короче); «Ботаники отвечают: вовсе не злак» → «если не злак? …она из семьи гречишных» (не повторять хук, сразу новое); ушли «дикая гречиха растёт там до сих пор» и «у нас» в панике — длина. Длина est ≈ 78,5 с.
