# 018 — Пицца Маргарита (правила v1 + сценарий-цепочка ТОМ-ТУР + ПОДПИШИСЬ)

Хук — **улика-подделка** (новый тип: «экспертиза документа»): «Письмо королевы о пицце висит в пиццерии Неаполя. А если оно — фальшивка?» → ответ ★ в s7 (~80 %).
Структура — **детектив по трём уликам**: легенда → корни (997) → еда бедняков + шутка Морзе → «Так была ли королева?» → улика 1, 2, 3 → разгадка → сегодня (число-сувенир 90 с) → «А или Б?».
≈ 61 с · укус: Том откусывает горячую Маргариту — сыр тянется нитью до самого письма на стене · Том-малыш: бродит по гигантской пицце — прыгает на моцарелле-батуте, прячется под базиликом от капли томата, лопает пузырь корочки · карта: Неаполь — Гаэта.
Факты и источники — `docs/sources/018-pizza.md`. Слушается без картинки: каждая реплика отвечает на предыдущую.

Карточка рецепта: 997 «лепёшка» → XIX в. «лепёшка + сало / сыр / рыбка» → 1866 «+ томат, моцарелла, базилик» → 1889 «имя Маргарита (легенда)» → сегодня «тесто 0,25 см, 485°, 90 с».
Костюмы: худи + фартук · ливрея лакея · средневековый арендатор · разносчик · сыщик · лаборант-эксперт · Том-малыш в колпаке пиццайоло · костюм 30-х · пиццайоло.
Палитра: ночь с оранжевой печью → золото дворца → серо-охряный камень и синее море → солнечная терракота с бельём → сепия под газовым фонарём → зелёная лампа архива → красно-бело-зелёная пицца в муке → чёрно-красный ар-деко → тёплая печь и зелёный кафель.
Пауза-гэги: Морзе морщится — точки-тире над головой (street); пузырь корочки лопается под Томом-малышом (pizza).

Критик (docs/script-research.md §9): хук с предметом и вопросом ✓ · ответ на ~80 % ✓ · миф зрителя (легенда) ✓ · «но/поэтому/улика» между репликами ✓ · повторный хук на каждой остановке (улика 1/2/3) ✓ · поворот+шутка на 35–45 % (Морзе) ✓ · число-сувенир 90 секунд ✓ · шутка до 35 с ✓ · без терминов (пиццайоло → «пекарь») ✓ · финал-петля + «письму или историкам?» ✓ → **9/10**. Минус: «через сорок лет» — округление (1889 → 1930-е).
