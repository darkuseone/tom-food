# 019 — Бургер (правила v1 + сценарий-цепочка + ПОДПИШИСЬ)

Хук — **загадка имени, открытая петля**: «Гамбургер — значит, из Гамбурга? Тогда почему за его родину спорят шесть городов?» → ответ ★ в s7 (~80 %).
Структура — **блюдо-путешественник по карте**: порт Гамбурга (котлета без булки) → пароходы в Нью-Йорк → ярмарка: котлету сунули в булку → версии-претенденты (без вердикта) → ложный финал «Гамбург, штат Нью-Йорк!» → 1918 «сэндвич свободы» = имя немецкое → ★ котлета и имя из Гамбурга, булка американская → сегодня 1 500 в секунду → «булка или вилка?».
≈ 60 с · укус: Том в ночном дайнере откусывает бургер — сок и кетчуп капают · Том-малыш: лезет по гигантскому бургеру (булка-купол, сыр-водопад, котлета-скала) · карта: Гамбург → Атлантика → Нью-Йорк → ярмарки США.

Карточка рецепта: XVII–XIX вв. «рубленая говядина, лук, соль» → 1847 «котлета в дорогу» → 1885 «+ булка» → 1918 «имя: „сэндвич свободы“ (зачёркнуто)» → сегодня «булка, котлета, сыр, кетчуп, горчица, огурчик».
Костюмы: повар дайнера (бумажная пилотка) + фартук · мясник в кожаном фартуке · эмигрант в кепке · ярмарочный продавец в канотье · картограф · ярмарка (canotье) · газетчик 1918 · Том-малыш-альпинист · бургер-повар.
Палитра: ночной дайнер, красно-бирюзовый неон → серо-стальной туманный порт с охрой кирпича → холодная сталь Атлантики и пар → тёплая ярмарка, полосатые шатры, горчица и кетчуп → тёмно-синий штаб с картой → сумеречная ярмарка с гирляндами → сепия 1918 с красными плакатами → кетчупово-горчичный бургер-мир → бургер-бар с огнём гриля.
Пауза-гэги: вилка втыкается в землю, котлета шлёпается в булку (fair); капля кетчупа плюхается рядом с Томом-малышом (burger).
Финал: «Пиши блюдо — положим его в булку!» (новая).

Критик (docs/script-research.md §9): хук с предметом/числом (Гамбург, шесть городов) и вопросом ✓ · ответ на ~80 % ✓ · миф зрителя («из Гамбурга, значит немецкий») ✓ · «но/поэтому» между репликами ✓ · повторный хук на остановках (ярмарка, «все первые», ложный финал, «не спеши») ✓ · поворот+шутка на 40–50 % («Все — первые») ✓ · число-сувенир 1 500/с ✓ · шутка до 35 с ✓ · без терминов ✓ · финал-петля + «булка или вилка?» ✓ → **9/10**. Минус: «шесть городов» — подсчёт версий (5 в США + Гамбург), формулировка округлая.
