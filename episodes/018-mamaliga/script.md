# 018 — Мамалыга (правила v1 + ПОДПИШИСЬ)
**Хук** — вопрос-загадка, открытая петля: «Налоговая лазейка сварила эту кашу! Какая?» → ★ разгадка в s7 (~75 %): султан брал налог пшеницей, кукурузу не облагал.
**Структура** — «детектив зерна»: просо Рима → Колумб → кукуруза в Молдавии → ритуал нитки → «Дракула» ест мамалыгу → ↻ месть кукурузы (пеллагра) → ★ налог султана → сегодня.
**Длина** ≈ 58 с · **Укус** — Том отламывает рукой кусок мамалыги, макает в сметану с брынзой (пар, тянется) · **Том-малыш** — в постолах и кушме бродит по гигантской жёлтой горе мамалыги на доске: брынза-валуны, озеро сметаны, шкварки-брёвна; сверху опускается гигантская нитка и режет гору в шаге от него (пауза-гэг).
Повороты ↻: s2 (Колумб), s6 (пеллагра). Паузы-гэги: thread (нитка в шаге от малыша), dracula (летучая мышь стаскивает ложку).
